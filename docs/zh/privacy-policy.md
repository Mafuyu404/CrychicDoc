# 隐私政策

最后更新：2026 年 9 月 10 日

本隐私政策适用于 CrychicDoc（以下简称“本网站”）。网站地址为 <https://docs.variedmc.cc>。本政策说明我们收集、使用、保存和删除信息的方式。

## 我们收集的信息

- **访问日志**：网站托管服务可能记录 IP 地址、浏览器类型、访问时间和请求地址，用于安全、故障排查和性能统计。
- **你主动提供的信息**：当你通过 GitHub 联系我们或提交问题时，我们会收到你在对应平台公开或主动提交的账号信息与消息内容。
本网站不提供 Pinterest 登录、账号连接、Pin 发布或 Board 管理功能，也不会从 Pinterest 接收或保存你的账号令牌。PickAID 可能在制作和宣传本网站相关视频时，按照 Pinterest 的规则使用 Pinterest 作为外部素材或工作流平台；这类使用发生在本网站之外，相关数据由 Pinterest 按其隐私政策处理。

## Cookies 和第三方服务

本网站本身不要求注册，也不使用广告追踪 Cookie。VitePress、GitHub、Discord、QQ、Algolia 和 Pinterest 等外部服务在你访问其链接或使用对应服务时，可能按照各自政策处理数据。

## 保存期限与删除

如果你通过 GitHub 联系我们，我们只在处理问题所需的期限内保留相关消息。你可以通过 [CrychicDoc GitHub 仓库](https://github.com/PickAID/CrychicDoc) 提交删除请求；收到请求后，我们会删除由我们控制的相关信息，法律要求保留的记录除外。

## 数据安全

我们会采取访问控制、最小权限和传输加密等合理措施保护信息。互联网传输和第三方平台不存在绝对安全保证；如发现可能影响你的信息安全事件，我们会在适用法律要求的范围内通知你。

## 儿童隐私

本网站不面向 13 岁以下儿童，也不会明知收集其个人信息。

## 政策变更

我们可能因功能、法律或服务变化更新本政策。更新后的版本会发布在本页面，并修改“最后更新”日期。

## 联系我们

隐私问题和数据删除请求请在 [CrychicDoc GitHub 仓库](https://github.com/PickAID/CrychicDoc) 提交 Issue，并在标题中注明“隐私请求”。
